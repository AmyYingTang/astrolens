# astrolens

An interactive astronomical image reader. Upload a deep-sky photo, get a structured reading
report anchored to specific spots on the image.

## Quick start (Phase 1 MVP)

Requires Node ≥ 18 and the [`claude` CLI](https://claude.com/claude-code) (BYO subscription,
only needed for `read`).

### Easiest: the `quickastrolens` wrapper

`quickastrolens` is a thin shell wrapper around the CLI for the common workflow — it
auto-builds on first use and runs read + render in one step.

```bash
./quickastrolens setup                              # install deps + build (first time)
./quickastrolens read path/to/photo.jpg "Sh2-308"   # read + render in one go
./quickastrolens read path/to/photo.jpg "NGC 6357" en   # English output
```

Output lands in `out/<image-name>/` as `report.json`, `image.jpg`, and `annotated.jpg`.

Other subcommands:

```bash
./quickastrolens build                       # rebuild
./quickastrolens render out/foo/report.json  # re-render only (no claude call)
./quickastrolens help
```

### Or use the underlying CLI directly

```bash
pnpm install
pnpm build

# Generate a reading from an image
node packages/cli/dist/index.js read path/to/photo.jpg --hint "Sh2-308" --out ./out

# Render the report to an annotated image
node packages/cli/dist/index.js render ./out/report.json
# -> ./out/annotated.jpg
```

`read` options: `--hint <name>`, `--lang zh|en` (default `zh`), `--out <dir>`,
`--model <model>`, `--no-simbad`.

Phase 1 ships the `read` and `render` commands only. Editor, embed, poster, and viewer are
later phases (see `astrolens-design.md`).

## Examples

`examples/` holds sample outputs (`report.json` + `image.jpg` + `annotated.jpg`) generated by
this tool — e.g. `examples/sh2-308/` and `examples/ngc6357/`. Each is self-contained, so
`node packages/cli/dist/index.js render examples/sh2-308/report.json` re-renders it.
